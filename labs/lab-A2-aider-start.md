# Lab Exercise: Using aider

__Objective__: Use aider to complete coding tasks. 

## Prerequisites
- Basic familiarity with code editing
- OpenAI or Claude API keys

## Exercise Overview

This lab explores the aider tool.

### Part 1: Environment setup and simple "Hello" app

1. Verify your environmant setup as per the "Introduction to aider" chapter, and activate your Python / aider environment.
2. Create a new working directory and cd into it.
3. Copy the files from thecodeSamples/simple-login folder.
4. Use aider to add a "Forgot password" feature. Focus on the UI for now, rather than the technical details of sending emails.

### Part 2: Further tasks

1. Use aider to carry out other tasks that you performed in earlier lab exercises, as a comparison.


## Wrap-up
By completing this lab, you should now be familiar with the basics of aider.
